# AGENTS.md

## 1. 项目定位

这是一个以学习为主要目标的项目。

主要学习目标：

- TS、NestJS、MikroORM
- TS企业级后端
- 理解实现原理，而不只是得到可以运行的代码

项目优先级：

1. 正确理解概念
2. 代码清晰、容易调试
3. 能够独立复现
4. 最后才考虑性能优化和复杂架构

除非用户明确要求，不要为了更专业而引入复杂设计。
